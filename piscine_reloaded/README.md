# piscine_reloaded (Mojo)

Mojo remake of Piscine Reloaded drills: control flow, recursion, strings,
file I/O, and small algorithms. Exercises `ex00`–`ex27` mirror the C curriculum
intent, not line-by-line C syntax.

```bash
pixi run mojo run piscine_reloaded/ex00/main.mojo
pixi run mojo run piscine_reloaded/ex14/main.mojo 5
pixi run mojo run piscine_reloaded/ex27/main.mojo pixi.toml
```
