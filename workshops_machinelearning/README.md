# workshops_machinelearning (Mojo)

42AI-style warmups, Mojo-native:

1. Tensor-free numerics with `List` / nested lists
2. Simple linear regression via normal equations (2D)
3. Mini k-means on toy points

```bash
pixi run mojo run workshops_machinelearning/linear_regression.mojo
pixi run mojo run workshops_machinelearning/kmeans.mojo
```
